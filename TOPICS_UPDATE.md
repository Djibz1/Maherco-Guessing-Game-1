- Gaming: Video Games, PlayStation, Xbox, Nintendo, Game Characters, Gaming Franchises, Esports, Open-World Games

- Technology: Tech Companies, Phones, Computers, AI, Internet, Social Media

The host can select any combination. A 10-round set is randomly generated from the selected topics when the room is created. Selected topic count is visible in the lobby to all players.
